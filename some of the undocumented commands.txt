SoundLength
Type: Function (numeric expression) — returns a floating-point value.

What it does: Returns the length/duration in seconds of a sound.

Arguments:

SoundLength (no parentheses / no args) 
	returns the length of the most recently played sound (internally passes -1, which SoundSystem::length() maps to the last soundID).
SoundLength(player#) 
	returns the length of a specific sound player, where player# is the integer ID returned by SoundPlayer(...).

SoundLoad(x)   
SoundLoad (string expression)
	It is a function.
	Reads the file fully into memory (or downloads the URL) once, stashes the bytes under a handle, and returns that handle as a string — literally "sound:" + x . It plays nothing and creates no player.
	Creates a reusable sound resource ahead of time (without playing it). 
    The returned string can then be passed to Sound, SoundPlay, or SoundPlayer so the same sound doesn't have to be re-decoded each time.
	What SoundLoad buys you is that the disk read or download happens once, and every subsequent SoundPlay res$ plays straight from RAM. That's the win for a sound effect fired repeatedly in a game loop, or for a URL you don't want to re-fetch. The cost is that the bytes stay resident.

SoundLoad(filename$)           — loads from a local file path.
SoundLoad(url$)                — loads from an http, https, or ftp URL (downloaded into a byte array).
SoundLoad(frequency, duration) — the two-argument form (args_ee): builds a 1-row × 2-column array (musical note/frequency + duration) and generates a tone resource from it. 
An array of note/duration pairs is likewise accepted.

SoundWait 
	block the interpreter — keeping the app (and the sound thread's event loop) alive — for the full duration, and you'll hear it.
	a backend-independent fallback is simply 'pause SoundLength', which parks the program for the clip's length while the background player renders.
	

SoundPlay x
	It is a statement. 
	It creates a sound instance, starts it, and returns immediately without waiting. It accepts four different argument types
	1. a SoundLoad handle (res$)		plays from the in-memory bytes (SOUNDTYPE_MEMORY)
	2. a plain filename or URL			QMediaPlayer reads it from disk/network itself (SOUNDTYPE_FILE / SOUNDTYPE_WEB)
	3. a player# from SoundPlayer		starts or resumes that existing instance
	4. an array of note/duration pairs	plays generated tones

Sound x is the blocking twin of SoundPlay — same arguments, but it waits for playback to finish before the next line runs. Same code path, it just calls sound->wait(id) afterwards.
SoundPlayer(x) is the function that gives you the id — it builds the instance without starting it. That's the one you need whenever you want to address a specific sound later with SoundLength, SoundSeek, SoundPause and friends, which all take an int id. 

!! Each SoundPlay res$ with a string creates a new instance with a new id (lastIdUsed++). Fire it in a loop and you'll stack up instances — up to SOUND_MAX_INSTANCES, after which you get ERROR_TOOMANYSOUNDS. Playing via a SoundPlayer id reuses the one instance instead.
