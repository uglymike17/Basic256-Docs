## Mid

### Format

mid ( *Zeichenkette*, *Startindex*, *Länge* )

### Beschreibung

Gibt ein *Länge* Zeichen langes Teilstück der *Zeichenkette* zurück, startend bei*Startindex*.

### Beispiel

’ ’ Die Zeile

    print mid("Hello", 2, 3)
