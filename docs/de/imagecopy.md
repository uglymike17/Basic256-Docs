## ImageCopy (Function)

### Format

**imagecopy** ( [x](../en/integerexpressions.md), [y](../en/integerexpressions.md), [w](../en/integerexpressions.md), [h](../en/integerexpressions.md) )

returns [internal_image_identifier](../en/stringexpressions.md)

### Description

Copy area of image from the graphics output window into memory and returns a string with an identifier for use with the other Image\* functions and statements.
