## Unserialize (Function)

### Format

variable = **unserialize** ( [string_expression](../en/stringexpressions.md) )

returns a [list](../en/lists.md) of values that should be assigned to a variable (creating an array)

### Description

The unserialize function returns a list of values. These values are stored in a “serialized” string with a very specific format.
