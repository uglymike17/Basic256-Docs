## LastErrorLine (Function)

### Format

**lasterrorline**\
**lasterrorline** ( )

returns [integer_expression](../en/integerexpressions.md)

### Description

Returns the line number in the program where the last trapped runtime error happened. For an error inside a [Subroutine](../en/subroutine.md) or [Function](../en/function.md), it is the line inside it.
