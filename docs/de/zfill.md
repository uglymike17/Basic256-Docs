## zfill (Function)

### Format

**zfill** ( [string_expression](../en/stringexpressions.md), [length_expression](../en/integerexpressions.md))

returns [string_expression](../en/stringexpressions.md)

### Description

Return a right justified string of at least [length_expression](../en/integerexpressions.md) with zeros appended to the right. it is equivalent to **rjust** ( [string_expression](../en/stringexpressions.md), [length_expression](../en/integerexpressions.md), “0”).
