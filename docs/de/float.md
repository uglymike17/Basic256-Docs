## Float (Function)

### Format

float ( [expression](../en/expressions.md) )

returns [float_expression](../en/floatexpressions.md)

### Description

Convert [expression](../en/expressions.md) to a floating point (decimal) number. Float will convert a string or an integer to a decimal value. If the expression can not be converted then a zero will be returned.
