### Numerische Konstanten

Numerische Konstanten sind natürliche Zahlenzeichen.
Ein optionales Minus-Zeichen kann vorangestellt werden, um negative Zahlen darzustellen.
Ein optionaler Dezimalpunkt, gefolgt von Ziffern, kann folgen, um Fliesskommazahlen zu erhalten.

| Dezimalzahlen |
|---------------|
| 10            |
| -234.56       |
| 56.78         |
| 0.0123        |

| Andere Zahlensysteme         |           |     |
|------------------------------|-----------|-----|
| Hexadezimalsystem (Basis 16) | print 0xA | 10  |
