## FromOctal (Function)

### Format

FromOctal ( [string_expression](../en/stringexpressions.md) )

returns [integer_expression](../en/integerexpressions.md)

### Description

This function returns an integer number represented by the Octal (base 8) string.

### Example

    print FromOctal("33")

Results in

    27
