## Volume (Statement)

### Format

**volume** *posint_expr*\
**volume** ( *posint_expr* )

### Description

Adjust the amplititude of the notes played with the [Sound](../en/sound.md) command. Levels must be numeric values from 0 to 10. The default is 5.
