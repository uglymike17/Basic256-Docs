## Acos (Function)

### Format

**acos** ( [numeric_expression](../en/numericexpressions.md) )

returns [float_expression](../en/floatexpressions.md)

### Description

Computes the arc-cosine of [expression](../en/expressions.md). Angles are expressed in radians (0 to 2pi).
