## NetClose (Statement)

### Format

**netclose**\
**netclose** ( )\
**netclose** [network_socket_number](../en/integerexpressions.md)\
**netclose** ( [network_socket_number](../en/integerexpressions.md) )

### Description

Close the specified network connection (socket). If [network_socket_number](../en/integerexpressions.md) is not specified socket number zero (0) will be used.

### Example

See example of usage on [NetConnect](../en/netconnect.md) page.
