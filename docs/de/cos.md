## Cos

### Format

**cos** ( *Ausdruck* )

### Beschreibung

Berechnet den Kosinus von *Ausdruck*. *Ausdruck* muss ein Bogenmaß sein.

### Note

Die cos-Funktion liefert kein besonders genaues Ergebnis.

### Siehe auch

[Sin](./sin.md), [Tan](./tan.md)

### Beispiel

    c = cos( 2*PI*deg/360)
