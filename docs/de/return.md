## Return (Statement)

### Format

In the context of a [gosub](../en/gosub.md) and within a [Subroutine](../en/subroutine.md):

**return**

In the context of a [Function](../en/function.md):

**return** [numeric_expression](../en/numericexpressions.md)\
**return** [string_expression](../en/stringexpressions.md)

### Description

The return statement is used with the [GOSUB](../en/gosub.md) statement to return control to the next statement, within a [SUBROUTINE](../en/subroutine.md) to return control from the subroutine, or with a [FUNCTION](../en/function.md) to return a value to the calling code.
