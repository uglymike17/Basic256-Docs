## Year

### Format

**year**\
**year** ( )

### Description

Returns the current system clock’s 4 digit year.

### See Also

[Day](./day.md), [Hour](./hour.md), [Minute](./minute.md), [Month](./month.md), [Second](./second.md)

### Example

    print "today's date is ";
    print (month + 1) + "/" + day + "/" + year

will display

    today's date is 11/30/2009

0.9.4
