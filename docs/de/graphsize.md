## Graphsize (Statement)

### Format

graphsize [graphich_width](../en/integerexpressions.md), [graphich_height](../en/integerexpressions.md)\
graphsize ( [graphich_width](../en/integerexpressions.md), [graphich_height](../en/integerexpressions.md) )

### Description

Changes the size of the graphics display window and redraws the BASIC256 application.
