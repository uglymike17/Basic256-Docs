## Pause

### Format

pause *Sekunden*

### Beschreibung

Hält die Programmausführung für die angegebene Anzahl Sekunden an. Der *Sekunden*-Wert kann eine Fließkommazahl sein, damit sind auch Pausen kleiner als eine Sekunde möglich.

### Beispiel

’ ’ pause 0.1’ ’
