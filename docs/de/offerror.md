## OffError (Statement)

### Format

**offerror**

### Description

Removes the last error trap defined with the [OnError](../en/onerror.md) statement. If all of the traps have been removed then error trapping is restored to the default behavior.

You may not execute an OffError statement inside a [Try / Catch / End Try](../en/try.md) statement.
