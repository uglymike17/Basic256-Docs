## WAVstate (Function)

### Format

**wavstate**\
**wavstate** ( )

returns [integer_expression](./integerexpressions.md)

### Description

Returns the playback status if the current autio file loaded by [WAVplay](./wavplay.md).

|       |             |
|-------|-------------|
| State | Description |
| 0     | Stopped     |
| 1     | Playing     |
| 2     | Paused      |
