## MkDir (Statement)

### Format

**mkdir** [string_expression](./stringexpressions.md)\
**mkdir** ( [string_expression](./stringexpressions.md) )

### Description

Create a directory/folder in the current working directory. If the directory already exists, no error will be displayed.
