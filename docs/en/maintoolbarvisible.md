## MainToolbarVisible (Statement)

### Format

**maintoolbarvisible** ( [boolean_expression](./booleanexpressions.md) )\
**maintoolbarvisible** [boolean_expression](./booleanexpressions.md)

### Description

Sets the view option for the main tool bar on the the window.

### Example

    maintoolbarvisible 0
    pause 2
    maintoolbarvisible 1
