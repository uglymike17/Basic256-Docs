## OutputToolbarVisible (Statement)

### Format

**outputtoolbarvisible** ( [boolean_expression](./booleanexpressions.md) )\
**outputtoolbarvisible** [boolean_expression](./booleanexpressions.md)

### Description

Sets the view option for the tool bar on the Text Output portion of the window.

### Example

    outputtoolbarvisible 0
    pause 2
    outputtoolbarvisible 1
