## Rjust (Function)

### Format

**rjust** ( [string_expression](./stringexpressions.md), [length_expression](./integerexpressions.md))\
**rjust** ( [string_expression](./stringexpressions.md), [length_expression](./integerexpressions.md), [fill_character](./stringexpressions.md))

returns [string_expression](./stringexpressions.md)

### Description

Return a right justified string of at least [length_expression](./integerexpressions.md) with [fill_character](./stringexpressions.md) appended to the left. If the [fill_character](./stringexpressions.md) is omitted a space will be used.
