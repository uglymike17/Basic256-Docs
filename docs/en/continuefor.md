## Continue For (Statement)

### Format

*for t = 1 to 100*\
(tab)[statement(s)](./programsyntax.md)\
(tab)**continue for**\
(tab)[statement(s)](./programsyntax.md)\
*next t*

### Description

Causes a for loop to jump over the remaining code to the next.
