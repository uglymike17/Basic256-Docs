## WAVpos (Function)

### Format

**wavpos**\
**wavpos** ( )

returns [float_expression](./floatexpressions.md)

### Description

Returns the current playback or paused position in decimal seconds of the current autio file loaded by [WAVplay](./wavplay.md).
