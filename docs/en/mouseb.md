## Mouseb (Function)

### Format

**mouseb**\
**mouseb** ( )

returns [integer_expression](./integerexpressions.md)

### Description

Returns the buttons that currently pressed on the mouse (if over the graphic output). Returns 0 if no click has been recorded.

| Return Values           |       |
|-------------------------|-------|
| Constant                | Value |
| MOUSEBUTTON_NONE        | 0     |
| MOUSEBUTTON_LEFT        | 1     |
| MOUSEBUTTON_RIGHT       | 2     |
| MOUSEBUTTON_CENTER      | 4     |
| MOUSEBUTTON_DOUBLECLICK | 32    |
