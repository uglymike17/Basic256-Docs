## Exp (Function)

### Format

**exp** ( [numeric_expression](./numericexpressions.md) )

returns [float_expression](./floatexpressions.md)

### Description

Returns the base of the natural logarithm *e* (approx: 2.718282) raised to the specified power. This is the inverse of the [Log](./log.md) function.

### Example

    print exp(1)
    print exp(log(10))

will print

    2.718282
    10
