## Spriteo (Function)

### Format

**spriteo** ( *sprite_number* )

returns [float_expression](./floatexpressions.md)

### Description

Returns the current opacity of the sprite, from 0.0 (fully transparent) to 1.0 (fully opaque). A sprite's opacity is set with the optional sixth argument of [Spriteplace](./spriteplace.md) and adjusted relatively by [Spritemove](./spritemove.md); a newly created sprite is fully opaque (1.0).

This is the opacity companion to the other sprite-property functions: [Spritex](./spritex.md), [Spritey](./spritey.md), [Spritew](./spritew.md), [Spriteh](./spriteh.md), [Spriter](./spriter.md) (rotation), [Sprites](./sprites.md) (scale), and [Spritev](./spritev.md) (visibility).
