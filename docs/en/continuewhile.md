## Continue While (Statement)

### Format

*while [boolean_expression](./booleanexpressions.md)*\
(tab)[statement(s)](./programsyntax.md)\
(tab)**continue while**\
(tab)[statement(s)](./programsyntax.md)\
*end while*

### Description

Causes a while loop to jump over the remaining code bacl to the top of the loop.
