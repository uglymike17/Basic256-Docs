## Write (Statement)

### Format

**write** [string_expression](./stringexpressions.md)\
**write** ( [string_expression](./stringexpressions.md) )\
**write** [open_file_number](./integerexpressions.md), [string_expression](./stringexpressions.md)\
**write** ( [open_file_number](./integerexpressions.md), [string_expression](./stringexpressions.md) )

### Description

Writes [string_expression](./stringexpressions.md) to the end of an open file. If the file number is not specified file number zero (0) will be used.
