## Unassign (Statement)

### Format

**unassign** [Variable](./variables.md)\
**unassign** [Array_Variable\[i](./arrayelements.md)\]\
**unassign** [Array_Variable\[row, col](./arrayelements.md)\]\
**unassign** [Map_Variable\[key](./mapelements.md)\]

### Description

Clears the contents of a variable, an array element, or a map element and sets its type to 0 (see [TypeOf](./typeof.md) and [Assigned](./assigned.md)).
