## FromOctal (Function)

### Format

FromOctal ( [string_expression](./stringexpressions.md) )

returns [integer_expression](./integerexpressions.md)

### Description

This function returns an integer number represented by the Octal (base 8) string.

### Example

    print FromOctal("33")

Results in

    27
