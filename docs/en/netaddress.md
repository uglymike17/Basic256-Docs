## NetAddress (Function)

### Format

**netaddress**\
**netaddress** ( )

returns [string_expression](./stringexpressions.md)

### Description

Returns a string with the IPv4 address of this machine on the local network.

See example of usage on [NetConnect](./netconnect.md) page.
