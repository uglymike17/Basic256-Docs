## Plot (Statement)

### Format

**plot** [x_position](./numericexpressions.md), [y_position](./numericexpressions.md)\
**plot** ( [x_position](./numericexpressions.md), [y_position](./numericexpressions.md) )

### Description

Changes the pixel located at [x_position](./numericexpressions.md),[y_position](./numericexpressions.md) in the graphics output window to the current color.
