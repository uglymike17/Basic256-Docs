## Exit While (Statement)

### Format

*while* [boolean_expression](./booleanexpressions.md)\
[statement(s)](./programsyntax.md)\
**exit while**\
[statement(s)](./programsyntax.md)\
*end while*

### Description

Causes program execution to jump to the first statement following the end while statement.
