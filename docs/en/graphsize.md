## Graphsize (Statement)

### Format

graphsize [graphich_width](./integerexpressions.md), [graphich_height](./integerexpressions.md)\
graphsize ( [graphich_width](./integerexpressions.md), [graphich_height](./integerexpressions.md) )

### Description

Changes the size of the graphics display window and redraws the BASIC256 application.
