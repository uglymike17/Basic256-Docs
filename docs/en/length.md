## Length (Function)

### Format

**length**( [string_expression](./stringexpressions.md) )\
**length**( [array](./arrays.md) )\
**length**( [map](./maps.md) )

returns [integer_expression](./integerexpressions.md)

### Description

Returns the number of characters in [string_expression](./stringexpressions.md), the number of elements in a map, or the number of values in an array.

NOTE: The length function returns the total number of items in a two dimensional array (rows \* columns).
