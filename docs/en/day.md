## Day (Function)

### Format

**day**\
**day** ( )

returns [integer_expression](./integerexpressions.md)

### Description

Returns the current system clock’s day of the month (1-31).

### See Also

[Day](./day.md), [Hour](./hour.md), [Minute](./minute.md), [Month](./month.md), [Msec](./msec.md), [Second](./second.md), [Year](./year.md)

### Example

    print "today's date is ";
    print (month + 1) + "/" + day + "/" + year

will print\|

    today's date is 11/30/2009
