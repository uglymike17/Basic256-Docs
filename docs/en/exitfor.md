## Exit For (Statement)

### Format

*for var = n to m*\
(tab)[statement(s)](./programsyntax.md)\
(tab)**exit for**\
(tab)[statement(s)](./programsyntax.md)\
*next var*

### Description

Causes program execution to jump to the first statement following the for statement.
