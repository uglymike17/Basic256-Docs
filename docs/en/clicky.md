## Clicky (Function)

### Format

**clicky**\
**clicky** ( )

returns [integer_expression](./integerexpressions.md)

### Description

Returns the mouse y location of the mouse pointer over the graphic output last time the user clicked a mouse button.

The position is measured in pixels unless a [Window](./window.md) has been set, in which case it is in the units that window defines. Use [ClickB](./clickb.md) to find out whether a click has happened at all.
