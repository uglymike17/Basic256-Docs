## LastErrorMessage (Function)

### Format

**lasterrormessage**\
**lasterrormessage** ( )

returns [string_expression](./stringexpressions.md)

### Description

Returns the message of the last trapped runtime error or warning, the same text BASIC-256 shows when the error is not trapped, without the "ERROR on line" part. The messages are listed on the [Error Codes](./errorcodes.md) page.

### Example

See examples of usage on [OnError](./onerror.md) and [LastError](./lasterror.md) pages.
