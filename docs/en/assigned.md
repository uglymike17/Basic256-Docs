## Assigned (Statement)

### Format

**assigned**([Variable](./variables.md))\
**assigned**([Array_Variable\[i](./arrayelements.md)\])\
**assigned**([Array_Variable\[row, col](./arrayelements.md)\])\
**assigned**([Map_Variable\[key](./mapelements.md)\])

returns [boolean_expression](./booleanexpressions.md)

### Description

Returns true if this variable, array element, or map element has been assigned a value.

displays\
