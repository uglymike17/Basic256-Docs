## Ceil (Function)

### Format

**ceil** ( [numeric_expression](./numericexpressions.md) )

returns [integer_expression](./integerexpressions.md)

### Description

Returns the lowest integer that is greater than or equal to [expression](./expressions.md).

| Value | int() | ceil() | floor() |
|-------|-------|--------|---------|
| -4.56 | -4    | -4     | -5      |
| -0.56 | 0     | 0      | -1      |
| 0.56  | 0     | 1      | 0       |
| 5.56  | 5     | 6      | 5       |
