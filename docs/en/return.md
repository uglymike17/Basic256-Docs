## Return (Statement)

### Format

In the context of a [gosub](./gosub.md) and within a [Subroutine](./subroutine.md):

**return**

In the context of a [Function](./function.md):

**return** [numeric_expression](./numericexpressions.md)\
**return** [string_expression](./stringexpressions.md)

### Description

The return statement is used with the [GOSUB](./gosub.md) statement to return control to the next statement, within a [SUBROUTINE](./subroutine.md) to return control from the subroutine, or with a [FUNCTION](./function.md) to return a value to the calling code.
