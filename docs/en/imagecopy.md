## ImageCopy (Function)

### Format

**imagecopy** ( [x](./integerexpressions.md), [y](./integerexpressions.md), [w](./integerexpressions.md), [h](./integerexpressions.md) )

returns [internal_image_identifier](./stringexpressions.md)

### Description

Copy area of image from the graphics output window into memory and returns a string with an identifier for use with the other Image\* functions and statements.
