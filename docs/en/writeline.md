## Writeline (Statement)

### Format

**writeline** [string_expression](./stringexpressions.md)\
**writeline** ( [string_expression](./stringexpressions.md) )\
**writeline** [open_file_number](./integerexpressions.md), [string_expression](./stringexpressions.md)\
**writeline** ( [open_file_number](./integerexpressions.md), [string_expression](./stringexpressions.md) )

### Description

Writes [string_expression](./stringexpressions.md) append with a newline character to the end of an open file. If the file number is not specified file number zero (0) will be used.
