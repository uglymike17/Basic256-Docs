## Sqr or Sqrt (Function)

### Format

**sqr** ( [numeric_expression](./numericexpressions.md) )\
**sqrt** ( [numeric_expression](./numericexpressions.md) )

returns [float_expression](./floatexpressions.md)

### Description

Returns the square root of the [numeric_expression](./numericexpressions.md).

### Example

    print sqr(2)
    print sqrt(10)

will print

    1.414214
    3.162278
