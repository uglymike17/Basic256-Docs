## Abs (Function)

### Format

**abs** ( [numeric_expression](./numericexpressions.md) )

returns [float_expression](./floatexpressions.md) or [integer_expression](./integerexpressions.md) depending on the type of expression passed.

### Description

Returns the absolute value of a [numeric_expression](./numericexpressions.md).

### Example

    print abs(-45)
    print abs(6.45)

will print

    45
    6.45
