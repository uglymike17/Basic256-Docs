## Readline (Function)

### Format

**readline**\
**readline** ( )\
**readline** ( [open_file_number](./integerexpressions.md) )

returns [string_expression](./stringexpressions.md)

### Description

Reads and returns an entire line from an open file. If the file number is not specified file number zero (0) will be used.
