## Chr (Function)

### Format

**chr** ( [numeric_expression](./numericexpressions.md) )

returns [string_expression](./stringexpressions.md)

### Description

Converts the integer [expression](./expressions.md) into a single character string expression with the UNICODE value of the number.

### See Also

[Asc](./asc.md)

### Example

    print chr(66)+chr(111)+chr(111)+chr(33)

will print

    Boo!
