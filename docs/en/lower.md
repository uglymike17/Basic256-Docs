## Lower (Function)

### Format

**lower** ( [string_expression](./stringexpressions.md) )

returns [string_expression](./stringexpressions.md)

### Description

Returns [string_expression](./stringexpressions.md) with all alphabetic characters converted to lower case.

### See Also

[Upper](./upper.md)

    print lower("BlUe!")

will display

    blue!
