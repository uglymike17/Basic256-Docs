## Clg (Statement)

### Format

**clg**\
**clg** [color_name](./colorconstants.md)\
**clg** ( [color_name](./colorconstants.md) )\
**clg** [rgb_expression](./rgb.md)\
**clg** ( [rgb_expression](./rgb.md) )\
==== Description ====
Clears the graphics output window or sets it to the specified color.
