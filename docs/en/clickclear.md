## Clickclear (Statement)

### Format

**clickclear**\
**clickclear** ( )

### Description

Sets ClickB, Clickx, and Clicky to zero so that we can easily tell when the next mouse click is recorded.

### Example

See sample program on [Clickb](./clickb.md).
