## WAVlength (Function)

**Obsolete.** The WAV statements are obsolete. Running one prints a warning — `WAVPLAY suite is obsolete. Use SOUND/SOUNDPLAY/SOUNDPLAYER instead`. Use [SoundLength](./soundlength.md) instead.

### Format

**wavlength**\
**wavlength** ( )

returns [float_expression](./floatexpressions.md)

### Description

Returns the length in decimal seconds of the current autio file loaded by [WAVplay](./wavplay.md).
