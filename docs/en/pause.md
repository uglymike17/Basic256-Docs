## Pause (Statement)

### Format

**pause** [numeric_expression](./numericexpressions.md)\
**pause** ([numeric_expression](./numericexpressions.md))

### Description

Halts execution for the specified number of seconds. The value of seconds may be a decimal value, so sub-second precision is possible.
