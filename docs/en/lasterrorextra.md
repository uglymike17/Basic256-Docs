## LastErrorExtra (Function)

### Format

**lasterrorextra**\
**lasterrorextra** ( )

returns [string_expression](./stringexpressions.md)

### Description

Returns statement specific "extra" information about the last error that was trapped. For most errors it is an empty string.

See examples of usage on [OnError](./onerror.md) and [LastError](./lasterror.md) pages.
