## Ljust (Function)

### Format

**ljust** ( [string_expression](../en/stringexpressions.md), [length_expression](../en/integerexpressions.md))\
**ljust** ( [string_expression](../en/stringexpressions.md), [length_expression](../en/integerexpressions.md), [fill_character](../en/stringexpressions.md))

returns [string_expression](../en/stringexpressions.md)

### Description

Return a left justified string of at least [length_expression](../en/integerexpressions.md) with [fill_character](../en/stringexpressions.md) appended to the right. If the [fill_character](../en/stringexpressions.md) is omitted a space will be used.
