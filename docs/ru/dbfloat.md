### DBFloat

#### Формат:

**dbfloat** ( номер\_колонки )

#### Описание:

Возвращает число с плавающей точкой (десятичную дробь) из указанной колонки результата SQL-запроса к базе. Больше информации о базах данных и, в частности, об SQLite можно найти на домашней странице SQLite <http://sqlite.org> и странице SQL на Wikipedia <http://ru.wikipedia.org/wiki/SQL>.
