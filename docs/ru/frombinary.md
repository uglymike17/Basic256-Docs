## FromBinary (Function)

### Format

**frombinary** ( [string_expression](../en/stringexpressions.md) )

returns [integer_expression](../en/integerexpressions.md)

### Description

This function returns an integer number represented by the binary (base 2) string.

### Example

    print frombinary("11")
    print frombinary("1001101")

displays\

    3
    77
