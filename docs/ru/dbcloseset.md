### DBCloseSet

#### Формат:

**dbclose**set\
**dbclose**set( )

#### Описание:

Закрывает текущий открытый [DBOpenSet](./dbopenset.md) запрос. Больше информации о базах данных и, в частности, об SQLite можно найти на домашней странице SQLite <http://sqlite.org> и странице SQL на Wikipedia <http://ru.wikipedia.org/wiki/SQL>.
