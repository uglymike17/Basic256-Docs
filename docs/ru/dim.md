### Dim

#### Формат:

**dim** числовая\_переменная( целое )\
**dim** строковая\_переменная\$( целое )\
**dim** числовая\_переменная( ряд, колонка )\
**dim** строковая\_переменная\$( ряд, колонка )

#### Описание:

Создает одномерный массив заданной длины или двумерный массив заданного размера, адресуемый через номер ряда и колонки. В зависимости от типа переменной массива создается числовой или строковый массив. Первый элемент массива имеет номер 0 (нуль). Индекс лежит в диапазоне от 0 до length-1.

#### Пример:

    dim z(5)
    z = {1, 2, 3, 4, 5}
    print z[0] + " " + z[4]
