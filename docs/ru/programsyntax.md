### Синтаксис программы

Программа на BASIC-256 состоит из списка операторов (команд), записанных по одному на строке и выполняющихся по очереди. Например:

    print "1я строка"
    print "2я строка"

выведет

    1я строка
    2я строка

Кроме того, существуют операторы, позволяющие изменять последовательный порядок выполнения команд:

- [Goto](./goto.md) (переход по метке),
- [If / Then](./ifthen.md) (проверка условия),
- [For / Next](./fornext.md), [Do / Until](./dountil.md), [While / End While](./whileendwhile.md) (циклы),
- [Gosub / Return](./gosubreturn.md) (подпрограммы)
