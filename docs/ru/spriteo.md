## Spriteo (Function)

### Format

**spriteo** ( *sprite_number* )

returns [float_expression](../en/floatexpressions.md)

### Description

Returns the current opacity of the sprite, from 0.0 (fully transparent) to 1.0 (fully opaque). A sprite's opacity is set with the optional sixth argument of [Spriteplace](../en/spriteplace.md) and adjusted relatively by [Spritemove](../en/spritemove.md); a newly created sprite is fully opaque (1.0).

This is the opacity companion to the other sprite-property functions: [Spritex](../en/spritex.md), [Spritey](../en/spritey.md), [Spritew](../en/spritew.md), [Spriteh](../en/spriteh.md), [Spriter](../en/spriter.md) (rotation), [Sprites](../en/sprites.md) (scale), and [Spritev](../en/spritev.md) (visibility).
