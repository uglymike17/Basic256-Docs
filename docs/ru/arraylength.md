## ArrayLength (Function)

### Format

variable **\[?\]**\
variable **\[?,\]**\
variable **\[?\]\[\]**\
variable **\[,?\]**\
variable **\[\]\[?\]**

returns [numeric_expression](../en/numericexpressions.md)

### Description

|           |                 |                                 |
|-----------|-----------------|---------------------------------|
| \[?\]     | One Dimensional | dimensioned length of the array |
| \[?,\]    | Two Dimensional | returns the number of rows      |
| \[?\]\[\] | Two Dimensional | returns the number of rows      |
| \[,?\]    | Two Dimensional | returns the number of columns   |
| \[\]\[?\] | Two Dimensional | returns the number of columns   |
