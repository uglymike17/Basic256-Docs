### Count

#### Формат:

**count**( строка, искомая\_строка )\
**count**( строка, искомое, регистр\_не_важен )

#### Описание:

Возвращает количество строк *искомая\_строка* в переменной или константе *строка*. Вы также можете указать дополнительное булево значение *регистр\_не_важен* = true, если хотите не учитывать регистр букв.

#### Смотри также:

[Countx](./countx.md)

#### Пример:

    print count("Привет", "ве")
    print count("Буйвол, буйвол, БуЙвОл.","БУЙВОЛ",true)

Будет напечатано

    1
    3
