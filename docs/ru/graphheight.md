### Graphheight

#### Формат:

**graphheight**\
**graphheight**()

#### Описание:

Возвращает высоту (размер по y) текущего окна для вывода графики.

#### Смотри также:

[Graphsize](./graphsize.md), [Graphwidth](./graphwidth.md)

#### Впервые в версии:

0.9.3
