### NetRead

#### Формат:

**netread**\
**netread**( )\
**netread**( номер\_сокета )

#### Описание:

Читает данные из сетевого соединения и возвращает их в виде строки. Эта функция ждет, пока происходит получение данных. Если *номер\_сокета*, используется нулевой (0) номер.
