### System

#### Формат:

system выражение\
system( выражение )

#### Описание:

Выполняет команду или другую программу и ждёт её завершения. Окно терминала не открывается, а всё, что команда выводит, теряется. Встроенные команды командной строки Windows (dir, copy, del) нужно запускать через cmd /c: system "cmd /c dir > files.txt". По умолчанию эта команда запрещена. Предупреждение: Эта команда может быть опасна. Используйте ее, если точно знаете, что вы делаете. Эта функция может быть отключена по соображениям безопасности. Включить или выключить эту функцию можно в меню Правка\>Настройки в панели меню программы.
