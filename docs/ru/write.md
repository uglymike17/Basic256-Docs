### Write

#### Формат:

**write** строка\
**write**( строка )\
**write** номер\_файла, строка\
**write**( номер\_файла, строка )

#### Описание:

Записывает строку в конец открытого файла. Если *номер\_файла* не указан, используется номер нуль (0).
