## Unassign (Statement)

### Format

**unassign** [Variable](../en/variables.md)\
**unassign** [Array_Variable\[i](../en/arrayelements.md)\]\
**unassign** [Array_Variable\[row, col](../en/arrayelements.md)\]\
**unassign** [Map_Variable\[key](../en/mapelements.md)\]

### Description

Clears the contents of a variable, an array element, or a map element and sets its type to 0 (see [TypeOf](../en/typeof.md) and [Assigned](../en/assigned.md)).
