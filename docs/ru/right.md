### Right

#### Формат:

**right**( строка, длина )

#### Описание:

Возвращает подстроку из строки, заданной параметром *строка*, указанной длины, начиная с правого края.

#### Смотри также:

[Mid](./mid.md), [Left](./left.md)

#### Пример:

    print right("Привет", 2)

Будет напечатано

    ет

#### Впервые в версии:

0.9.5b
