## Exit Do (Statement)

### Format

*do*\
(tab)[statement(s)](../en/programsyntax.md)\
(tab)**exit do**\
(tab)[statement(s)](../en/programsyntax.md)\
*until boolean_expr*

### Description

Causes program execution to jump to the first statement following the until statement.
