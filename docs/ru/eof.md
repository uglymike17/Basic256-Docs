### Eof

#### Формат:

**eof**\
**eof**()\
**eof**( номер\_файла )

#### Описание:

Возвращает двоичный флаг (истина/ложь) в качестве признака конца чтения файла EOF (на англ. End Of File - конец файла). Если *номер\_файла* не указан, используется значение нуль (0).
