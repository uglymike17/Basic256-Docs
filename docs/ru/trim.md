## Trim (Function)

### Format

**trim** ( [string_expression](../en/stringexpressions.md) )\
return [string_expression](../en/stringexpressions.md)

### Description

The **Trim** function removes all whitespace characters from both the beginning and ending of a string.\
[RTrim](../en/rtrim.md) trims only the right end and [LTrim](../en/ltrim.md) only trims the left end of the string.

### Notes

Whitespace means the ASCII characters chr(9) - Horizontal Tab, chr(10) - Newline, chr(11) - Vertical Tab, chr(12) - Formfeed, chr(13) - Carriage Return, ’ ’ - Space, and many others characetrs from UNICODE like: chr(0xA0) - No-break space, chr(0x2009) - Thin Space, and others.
