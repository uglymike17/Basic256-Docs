### Graphwidth

#### Формат:

**graphwidth**\
**graphwidth**()

#### Описание:

Возвращает ширину (размер по x) текущего окна для вывода графики.

#### Смотри также:

[Graphheight](./graphheight.md), [Graphsize](./graphsize.md)

#### Впервые в версии:
