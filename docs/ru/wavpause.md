## WAVpause (Statement)

**Obsolete.** The WAV statements are obsolete. Running one prints a warning — `WAVPLAY suite is obsolete. Use SOUND/SOUNDPLAY/SOUNDPLAYER instead`. Use [SoundPause](../en/soundpause.md) instead.

### Format

**wavpause**

### Description

Pause playing the current asynchronous (background) audio file.
