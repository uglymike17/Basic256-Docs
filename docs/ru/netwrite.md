### NetWrite

#### Формат:

**netwrite** string\
**netwrite**( строка )\
**netwrite** номер\_сокета, строка\
**netwrite**( номер\_сокета, строка )

#### Описание:

Посылает строку, заданную параметром *строка* в открытое сетевое соединение. Если *номер\_сокета*, используется нулевой (0) номер.
