## PenWidth (Statement)

### Format

penwidth [width](../en/numericexpressions.md)\
penwidth( [width](../en/numericexpressions.md) )

### Description

Set the width of the current drawing pen. The pen width is used in the drawing statements to define how wide the line, point, or border of a shape should be. The default width is 1 pixel wide. If no border is desired the width may be set to 0.
