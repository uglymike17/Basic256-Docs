## WAVseek (Statement)

**Obsolete.** The WAV statements are obsolete. Running one prints a warning — `WAVPLAY suite is obsolete. Use SOUND/SOUNDPLAY/SOUNDPLAYER instead`. Use [SoundSeek](../en/soundseek.md) instead.

### Format

**wavseek** ( [numeric_expression](../en/numericexpressions.md) )\
**wavseek** [numeric_expression](../en/numericexpressions.md)\

### Description

Moves the output location of the current autio file to a specific location (decimal seconds).
