# String bewerkingen

## Waarom

Als je met de computer iets met woorden wil doen, heeft de computer een aantal functies nodig om met de woorden en letters te leren spelen en werken.

## Welke opdrachten hebben we?

| Opdracht | Wat doet het |
|----|----|
| [Asc](./asc.md) | Geef de ASCII waarde van een karakter |
| [Chr](./chr.md) | Geef het karakter van de ASCII waarde terug |
| [Decimal](./decimal.md) | hoeveel cijfers na de komma wil je zien? |
| [Instr](./instr.md) | Een naald in een hooiberg zoeken…. |
| [Instrx](./instrx.md) | Een speciale naald in een hooiberg zoeken…. |
| [Count](./count.md) | hoeveel keer vind je mijn naald? |
| [Countx](./countx.md) | hoeveel keer vind je mijn *speciale* naald? |
| [Explode](./explode.md) | een string mooi splitsen |
| [Explodex](./explodex.md) | een sting mooi *speciaal* splitsen |
| [Implode](./implode.md) | apparte array elementen in één string plakken |
| [Left](./left.md) | het linkergedeelte van een string |
| [Length](./length.md) | hoe lang is een string? |
| [Lower](./lower.md) | vervangt hoodletters door kleine letters |
| [Mid](./mid.md) | neemt een middelste deel uit een string |
| [MD5](./md5.md) | Berekent een soort unieke onkraakbare code !!! Supergeheim! |
| [Replace](./replace.md) | de ene sting wordt door een andere vervangen |
| [Replacex](./replacex.md) | de ene sting wordt door een andere vervangen, ’t zelfde als het vorige, maar moeilijker (=) |
| [Right](./right.md) | als je enkel het rechste gedeelte van de string wil |
| [String](./string.md) | om getallen om te zetten in een string. |
| [Upper](./upper.md) | ALLEMAAL HOODLETTERS…. |
