## Log

### Formaat

log ( *expression* )

### Beschrijving

Geeft het [natuurlijk logaritme](http://nl.wikipedia.org/wiki/Natuurlijke_logaritme) van *expression* terug.

### Voorbeeld

``` basic4gl
a= 10
print a
print log(a)
```

geeft dan

    10
    2.302585
