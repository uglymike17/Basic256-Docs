## Radians

### Formaat

**radians** ( *expression* )

### Beschrijving

![radians.png](@site/static/img/wiki/en/radians.png)
Converteert een hoek in graden naar radianen.\

### Zie Ook

``` baci4gl
hoek = 360 
print "Hoek in graden: " + hoek
print "Hoek in radialen: " + radians(hoek)
```

geeft dan

    hoek = 360 
    Hoek in graden: 360
    Hoek in radialen: 6.283185

6.28 = 2\*pi
