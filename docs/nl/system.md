## System

### Formaat

**system** *uitdrukking*\
**system** ( *uitdrukking* )

### Beschrijving

Voert een commando of een ander programma uit en wacht tot het klaar is. Er wordt geen terminalvenster geopend en wat het commando afdrukt gaat verloren. Opdrachten die in de Windows-opdrachtprompt zelf zitten (dir, copy, del) hebben cmd /c ervoor nodig: system "cmd /c dir > bestanden.txt". De opdracht staat standaard uit; zie Voorkeuren/Geavanceerd/"Allow SYSTEM statement".\
:!: OPGELET: Dit kan een zeer gevaarlijke opdracht zijn. Gebruik dit enkel als je weet wat je doet.
