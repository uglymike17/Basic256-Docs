## Refresh

### Formaat

**refresh**

### Beschrijving

Deze functie ververst het grafisch venster om alles te tonen wat sinds het laatste refresh commando werd getekend. Deze functie wordt gebruikt samen met de [Fastgraphics](./fastgraphics.md) mode.

### Voorbeeld

``` basic4gl
nog uti te werken
```
