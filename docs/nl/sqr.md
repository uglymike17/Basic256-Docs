## Sqr of Sqrt

### Formaat

**sqr** ( *expression* )\
**sqrt** ( *expression* )

### Beschijving

Geeft de [viekantswortel](http://nl.wikipedia.org/wiki/Vierkantswortel) terug van *expression*[^1]

### Voorbeeld

``` basic4gl
print sqr(16)
print sqrt(100)
print sqr(2)
```

toont

    4
    10
    1.414214

### Nieuw vanaf

0.9.6.51
