## GraphToolbarVisible (Statement)

### Format

**graphtoolbarvisible** ( [boolean_expression](../en/booleanexpressions.md) )\
**graphtoolbarvisible** [boolean_expression](../en/booleanexpressions.md)

### Description

Sets the view option for the tool bar on the Graphics portion of the window.

### Example

    graphtoolbarvisible 0
    pause 2
    graphtoolbarvisible 1
