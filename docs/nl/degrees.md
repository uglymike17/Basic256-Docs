## Degrees

### Formaat

**degrees** ( *expression* )

### Beschrijving

![radians.png](@site/static/img/wiki/en/radians.png)

Deze functie converteert een hoek in radianen naar graden.

### Voorbeeld

``` basci4gl
print 2*pi
print degrees(2*pi)
```

geeft dan

    6.283185
    360
