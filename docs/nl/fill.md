## Fill (Statement)

### Format

#### Create a One Dimensional Array and Fill With a Value

**dim** [variable](../en/variables.md) ( [array_size](../en/integerexpressions.md) ) **fill** [expression](../en/expressions.md)\
**dim** [variable](../en/variables.md) \[ [array_size](../en/integerexpressions.md) \] **fill** [expression](../en/expressions.md)

#### Create a Two Dimensional Array and Fill With a Value

**dim** [variable](../en/variables.md) ( [array_size_rows](../en/integerexpressions.md) , [array_size_columns](../en/integerexpressions.md)) **fill** [expression](../en/expressions.md)\
**dim** [variable](../en/variables.md) \[ [array_size_rows](../en/integerexpressions.md) , [array_size_columns](../en/integerexpressions.md)\] **fill** [expression](../en/expressions.md)

#### Fill an Existing Array With a Single Value

**dim** [variable](../en/variables.md) **fill** [expression](../en/expressions.md)\
**dim** [variable](../en/variables.md)\[\] **fill** [expression](../en/expressions.md)\
[variable](../en/variables.md) **fill** [expression](../en/expressions.md)\
[variable](../en/variables.md)\[\] **fill** [expression](../en/expressions.md)

### Description

Fills a newly dimensioned or previously dimensioned array with a single value.
