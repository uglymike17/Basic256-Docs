## Mouseb

### Formaat

**mouseb**\
**mouseb**()

### Beschrijving

De functie geeft de huidige knop weer die ingedrukt wordt, naar analogie van [clickb](./clickb.md), alleen gaat het hier over de knop die op het moment zelf wordt ingedukt.

| Resultaten |                              |
|------------|------------------------------|
| Waarde     | Muisknop die wordt ingedrukt |
| 0          | Geen                         |
| 1          | Links                        |
| 2          | Rechts                       |
| 4          | Midden                       |
