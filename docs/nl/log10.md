## Log10

### Formaat

log10 ( *expression* )

### Beschrijving

De functie geeft de logaritme met grondtal 10 terug van *expression*.

### Voorbeeld

``` basic4gl
a= 10000
print a
print log10(a)
```

geeft

    10000
    4
