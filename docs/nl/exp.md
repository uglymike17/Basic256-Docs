## Exp

### Formaat

**exp** ( *exponent* )

### Beschrijving

Functie berekent *e<sup>x</sup>* (e=2.718282). Het is de omgekeerde functie van [Log](./log.md).

### Voorbeeld

``` basic4gl
print exp(1)
print exp(log(10))
```

ttont

    2.718282
    10

### Nieuw vanaf

0.9.6.51
