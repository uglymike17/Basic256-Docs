## PenWidth

### Format

penwidth *epaisseur*\
penwidth( *epaisseur* )

### Description

Défini l’épaisseur du stylo de dessin en pixel. La largeur par défaut est de 1 pixel. La largeur du stylo est utilisée dans les outils de dessins pour définir le tracé d’une ligne, d’un point, ou les bord d’une figure.
