## Volume

### Format

**volume** *niveau*\
**volume** ( *niveau* )

### Description

Ajuste le volume sonore des notes jouées par la commande [Sound](./sound.md). Le volume *niveau* est une valeur numérique comprise entre 0 et 10. Le volume par défaut est 5.

### Voir Aussi

[Sound](./sound.md)

### Disponible à partir de la version

0.9.5i
