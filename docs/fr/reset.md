## Reset

### Format

**reset**\
**reset()**\
**reset**(*numerofichier*)

### Description

Efface un fichier ouvert. Toutes les données du fichier sont perdues. Si *numerofichier* n’est pas spécifié, le numéro zéro (0) sera utilisé par défaut.
