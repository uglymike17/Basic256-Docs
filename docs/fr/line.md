## Line

### Format

**line** *x0*, *y0*, *x1*, *y1*\
**line**(*x0*, *y0*, *x1*, *y1*)

### Description

Trace une ligne reliant les points x0,y0 et x1, y1.

### Exemple

    color white
    rect 0,0,500,500
    color black
    line 100,100,400,400
    line 200,400,400,400
    line 200,400,100,100
