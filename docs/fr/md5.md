## MD5

### Format

**md5** ( *string* )

### Description

Retourne une chaîne de caractères contenant la somme de contrôle MD5 de l’argument *sring*.Cette fonction découle du RSA Data Security, Inc. MD5 Message-Digest Algorithm.

### Exemple

    print MD5("Something")
    print MD5("something")

Affichera :

    73f9977556584a369800e775b48f3dbe
    437b930db84b8079c2dd804a71936b5f
