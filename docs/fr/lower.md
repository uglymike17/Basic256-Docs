## Lower

### Format

**lower**( *string*)

### Description

Retourne la chaîne de caractère *string* avec tous les caractères alphabétiques convertis en minuscule.

### See Also

[Upper](./upper.md)

    print lower("La Plage Et Le Soleil !")

Affichera :

    la plage et le soleil !

### Disponible depuis la version

0.9.5e
