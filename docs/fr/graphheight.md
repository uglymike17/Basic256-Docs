## Graphheight

### Format

graphheight\
graphheight()

### Description

Retournes la hauteur (dimension Y) de la fenêtre d’affichage graphique courante.

### Voir Aussi

[Graphsize](./graphsize.md), [Graphwidth](./graphwidth.md)

### Disponible à partir de la version

0.9.3
