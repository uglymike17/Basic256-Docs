## NetClose

### Format

**netclose**\
**netclose** ( )\
**netclose** *numero_de_socket*\
**netclose** ( *numero_de_socket* )

### Description

Ferme la connexion réseau (socket) spécifée. si *numero_de_socket* n’est pas spécifié, zéro (0) est utilisé par défaut.

### Exemple

Voir la page [NetConnect](./netconnect.md).
