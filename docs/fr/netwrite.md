## NetWrite

### Format

**netwrite** *string*\
**netwrite** ( *string* )\
**netwrite** *socket_number*, *string*\
**netwrite** ( *socket_number*, *string* )

### Description

Envoie une chaîne de caractères vers une connexion réseau ouverte. Si *socket_number* n’est pas fourni, zéro (0) est utilisé par défaut.

### Exemple

Voir la page [NetConnect](./netconnect.md).
