## DBFloat

### Format

**dbfloat** ( *ColumnNumber* )

### Description

Retourne une valeur décimale (virgule flottante) de la *colonne demandée* de la ligne active de l’enregistrement ouvert.

Voir l’exemple de la page de [DBOpen](./dbopen.md).
