## Return

### Format

**return**\

### Description

L’instruction **return** est utilisée dans une portion de programme appelée par [GOSUB](./gosub.md) pour retourner le contrôle à l’instruction qui suit le [GOSUB](./gosub.md). Dans un sous-programme défini par [SUBROUTINE](./subroutine.md) ou une fonction définie par [FUNCTION](./function.md), **return** permet de rendre le contrôle au programme appelant.
