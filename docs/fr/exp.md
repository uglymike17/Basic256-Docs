## Exp

### Format

**exp** ( *exponent* )

### Description

Retourne l’exponentiel de l’argument *exponent* (soit e à la puissance *exponent*, e étant approximativement égal à 2.718282). La fonction inverse est [Log](./log.md).

### Exemple

    print exp(1)
    print exp(log(10))

Affichera :

    2.718282
    10

### Disponible depuis la version

0.9.6.51
