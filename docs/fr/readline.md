## Readline

### Format

**readline**\
**readline**()\
**readline**(*numerofichier*)

### Description

Lit et retourne une ligne entière depuis un fichier ouvert. Si le *numerofichier* n’est pas spécifié, le numéro zéro (0) sera utilisé par défaut.
