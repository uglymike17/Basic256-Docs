## Spritedim

### Format

**spritedim** *n*\
**spritedim** ( *n* )

### Description

Créé *n* emplacements en mémoire pour les “sprites”. Dans les programmes l’accès aux “sprites” passe par l’utilisation d’un nombre compris entre 0 et *n*-1.
