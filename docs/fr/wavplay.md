## WAVplay

### Format

**wavplay** *nom_de_fichier*\
**wavplay** ( *nom_de_fichier* )

### Description

Joue le fichier audio WAV *nom_de_fichier* en arrière plan (de façon asynchrone).

[WAVstop](./wavstop.md) [WAVwait](./wavwait.md)
