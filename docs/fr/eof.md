## Eof

### Format

eof\
eof()\
eof(*NuméroFichier*)

### Description

Retourne un drapeau binaire (vrai/faux) qui signale si la fin du fichier (EOF: End Of File) a été atreinte. Si *NuméroFichier* n’est pas spécifié alors le numéro zéro (0) sera utilisé par défaut.
