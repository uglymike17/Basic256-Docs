## Sqr or Sqrt

### Format

**sqr** ( *expression* )\
**sqrt** ( *expression* )

### Description

Retourne la racine carrée du nombre *expression*.

### Exemple

    print sqr(2)
    print sqrt(10)

Affichera :

    1.414214
    3.162278

### Disponible depuis la version

0.9.6.51
