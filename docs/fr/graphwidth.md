## Graphwidth

### Format

graphwidth\
graphwidth()

### Description

Retournes la largeur (dimension X) de la fenêtre d’affichage graphique courante.

### Voir Aussi

[Graphheight](./graphheight.md), [Graphsize](./graphsize.md)

### Disponible à partir de la version

0.9.3
