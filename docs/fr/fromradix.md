## FromRadix

### Format

**fromradix** ( *string*,*base* )

### Description

Retourne l’entier représenté par la chaîne de caractères *string* dans la base *base*.

### Exemple

    print fromradix("ffef",16)
    print fromradix("1001101", 2)
    print fromradix("a1z9",36)

Affichera :\

    65519
    77
    469125
